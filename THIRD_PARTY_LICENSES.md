# Third-party licenses

This repository contains Ploos-AS packaging and automation for the upstream EnergyMech IRC bot.

EnergyMech itself is not relicensed by Ploos-AS. The container build retrieves upstream EnergyMech source and the resulting image therefore contains software under EnergyMech's upstream license terms.

Before the first release, CI/release qualification must pin a specific upstream revision and this document must be updated with the exact upstream license identifier/text reference for that revision.
